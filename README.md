# Personal Portfolio

## Student Name
Naceri Rim Serine

## Project Description
A personal portfolio website built to showcase my dual background as a Cyber Security student and a Full Stack Web Developer. The website serves as a central hub for sharing my skills, professional summary, and highlighted projects, including platforms like Staris, Florestis, Poises, and an Anonymous Dispatches site. It provides an accessible and clean user experience for visitors wanting to get in touch.

## Technologies Used
* **HTML5:** Structuring the content and semantics.
* **CSS3:** Styling, layout, and responsive design, utilizing CSS variables and media queries.
* **JavaScript (Vanilla):** DOM manipulation for interactive elements such as the mobile navigation menu and dynamic year generation in the footer.

## Implemented Features
* **Responsive Design:** Optimized layout for seamless viewing across desktop, tablet, and mobile devices.
* **Mobile Navigation Menu:** Interactive hamburger menu for smaller screens, built with JavaScript toggling logic and CSS transitions.
* **Project Showcase:** A dedicated grid section to display featured personal projects.
* **Dynamic Footer:** Automatically updating copyright year using JavaScript.
* **Clean UI & Animations:** Smooth scrolling, hover states, and animated menu button transitions for an engaging user experience.
